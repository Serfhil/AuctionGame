# Баланс

Все числа правил лежат в `js/config.js`, а справочники (цены вещей, кошельки участников, реклама, жалованье) в `js/data/`.
Логика движка цифр не содержит.

## Симулятор

```bash
npm run simulate                     # 300 сезонов на политику
npm run simulate -- --runs 1000 --seed 7
```

Сезоны играют автоматические политики (`tools/policies.mjs`):

| Политика | Поведение |
| --- | --- |
| `careful` | берёт лоты без явных проблем, платит экспертизу за дорогие |
| `careful+staff` | то же, плюс нанимает штатного эксперта |
| `lazy` | берёт всё подряд, не проверяет подлинность |
| `dealer` | проверяет подлинность и выкупает вещи ниже рынка |

Колонки: медиана и квантили итогового капитала, доля побед, банкротств, скандалов с подделками за сезон, число проданных и непроданных лотов, итоговая репутация.

Ориентир (300 сезонов, seed 1):

| политика | медиана | победы | банкрот |
| --- | --- | --- | --- |
| careful | ≈ 41 000 € | 50% | 25% |
| careful+staff | ≈ 48 000 € | 56% | 25% |
| lazy | ≈ 10 000 € | 12% | 32% |
| dealer | ≈ 80 000 € | 72% | 8% |

Смысл: аккуратная игра выигрывает примерно в половине партий, невнимательная проигрывает, а умение выбирать и проверять заметно выгодно.

## Защитные тесты

`tests/season.test.js` держит эти соотношения:

- у аккуратного игрока доля побед между 30% и 80%;
- ленивый хуже аккуратного, дилер лучше;
- штатный эксперт снижает число скандалов;
- банкротство редкое для разумной игры.

Если тест упал после правки цифр, сначала запустите симулятор и оцените, что именно изменилось. Порог меняют только осознанно.

## Основные ручки

| Цель | Где |
| --- | --- |
| Сложнее или легче в целом | `FIXED_COSTS`, `START_CASH`, `GOAL`, `BUYER_PREMIUM` |
| Цены сделок для продавца | `BUYOUT_SHARE`, `GREEDY_SELLER_*`, `ESTIMATE_RANGE`, `RESERVE_SHARE` |
| Экспертиза | `EXPERT_FEE_MIN`, `EXPERT_FEE_SHARE`, `data/staff.js` |
| Подделки | `FAKE_CHANCE_*`, `FAKE_EXPOSURE_CHANCE`, `REPUTATION_EFFECTS.fakeExposed` |
| Зал | `MIN_BIDDERS`, `MAX_BIDDERS`, `data/bidder-classes.js`, `data/marketing.js` |
| Дуэль | объект `DUEL` |
| Частота событий | `EVENT_CHANCE`, `data/events.js` |

## Принцип цен

Рыночная цена вещи (`trueValue`) выбирается внутри вилки шаблона. Продавец называет оценку около рынка, иногда с завышением.
Выкуп предлагается за 60–85% от середины его оценки, поэтому цена выше рынка встречается лишь у жадных продавцов (около 20% случаев).
Участники готовы заплатить в диапазоне множителя своего класса от настоящей цены, и именно разрыв между ценой выкупа и потолками зала создаёт прибыль.
