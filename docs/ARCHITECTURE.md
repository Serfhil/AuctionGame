# Архитектура

## Слои

```
data/ + config.js   данные и числа (без логики)
      ↓
engine/             правила игры: чистые функции над объектом game, без DOM и таймеров
      ↓
ui/                 отрисовка, события, таймеры, звук, эффекты
      ↓
main.js             подключение к странице
```

Зависимости идут только вниз. `engine` не импортирует ничего из `ui`, и это даёт два свойства:
движок можно гонять в Node (тесты, симулятор), а интерфейс не содержит правил.

## Движок (`js/engine/`)

Состояние одно: объект `game`, его создаёт `createGame()` (`state.js`). Любая функция получает `game` первым аргументом и меняет его.
Глобального состояния нет.

| Файл | Назначение |
| --- | --- |
| `state.js` | создание игры, вместимость каталога, капитал, комиссия |
| `offers.js` | генерация предложений, принять, выкупить, отказать, платная экспертиза |
| `staff.js` | штатный эксперт и автоматическая оценка |
| `week.js` | начало недели, события |
| `bidders.js` | участники зала и телефонный клиент |
| `night.js` | открытие вечера, рассадка, переход между лотами, итоги вечера |
| `lot.js` | ход одного лота: ставки, дуэль, отсчёт, молоток, снятие |
| `pricing.js` | округление и шаг ставки |
| `reputation.js` | изменение репутации |
| `rating.js` | оценка сезона |

`lot.js` не знает о времени. Функция `stepLot(game, session)` делает один такт и возвращает список событий (`LotEvent`).
Когда вызывать такт, решает интерфейс.

### Случайность

`util/random.js` даёт засеваемый генератор (`seedRandom`) и помощники (`chance`, `pick`, `weightedPick`, `shuffle`).
С одним seed партия повторяется бит в бит; на этом держатся тесты и симулятор.
Чисто декоративная случайность интерфейса (конфетти) живёт отдельно в `ui/cosmetic.js`, чтобы не сбивать последовательность движка.

## Интерфейс (`js/ui/`)

- `app.js` — `createApp(root, { scheduler })`. Хранит `game`, рисует экран по `game.phase`, ловит клики.
  Любая кнопка размечена `data-act="имя"`; имя ищется в таблице `handlers`. Новое действие = новый обработчик.
- `screens/` — чистые функции `(game) → строка HTML`.
- `components/` — повторяющиеся куски (шапка, таблица лотов, панель штата).
- `night/` — сцена торгов: `controller.js` (таймеры и ход), `stage.js` (табло и отсчёт), `hall.js` (кресла), `result.js` (итог лота и эффекты).
- `effects.js`, `audio.js` — вспышки, тряска, конфетти, вибрация, звук. Всё уважает `prefers-reduced-motion`.
- `scheduler` передаётся извне. В браузере это `globalThis`, в тестах — ручной планировщик (`tests/helpers/fake-dom.js`).

## Стили (`css/`)

`tokens.css` (цвета, темы), `base.css` (сброс, шапка, кнопки), `screens.css` (экраны), `lots.css` (таблица лотов и штат), `auction.css` (сцена, зал, эффекты).
Светлая и тёмная темы переключаются по `prefers-color-scheme`.

## Сборка (`tools/build.mjs`)

ES-модули не открываются из `file://`, поэтому сборщик делает один HTML: вставляет CSS в `<style>` и склеивает модули в один скрипт.
Внешних пакетов нет, поэтому сборщик простой и накладывает правила на код:

1. Импорты только вида `import { a, b } from './file.js';`. Без псевдонимов, `import *` и пакетов.
2. Экспорты только `export const/let/function/class`. Без `export default` и `export { }`.
3. Имена верхнего уровня уникальны во всём проекте: после склейки все модули делят одну область видимости.
4. Циклов в зависимостях нет.

Нарушение останавливает сборку с понятным сообщением (`tests/build.test.js` проверяет каждый случай).

## Тесты

`npm test` запускает `node --test`:

- `util`, `offers`, `lot` — правила и случайность;
- `season` — воспроизводимость, инварианты, защита баланса;
- `ui` — прохождение партии через интерфейс на подставном DOM;
- `build` — сборка и ограничения сборщика.

## Как добавить

- **Событие:** запись в `data/events.js` с вариантами `{ label, hint, requiresCash, apply(game) }`; `apply` возвращает текст итога.
- **Категория вещей:** `data/categories.js`, шаблоны по четырём уровням.
- **Тип участника:** `data/bidder-classes.js`.
- **Реклама или уровень штата:** `data/marketing.js`, `data/staff.js`.
- **Экран или кнопка:** функция в `ui/screens/` и обработчик в `handlers` в `app.js`.
