# AuctionGame — «Последний лот»

Браузерная игра про управляющего аукционным домом. За 12 недель нужно довести капитал дома до 40 000 €:
принимать вещи у продавцов, отличать подлинники от подделок, готовить торги и самому вести вечерние аукционы
перед залом из живых участников.

Без фреймворков и зависимостей: чистый JavaScript (ES-модули), CSS и Node.js только для сборки, тестов и симулятора.

## Быстрый старт

Нужен Node.js 20 или новее.

```bash
npm start          # локальный сервер, затем открыть http://localhost:8080
npm test           # все тесты
npm run build      # один файл dist/auction.html, открывается двойным кликом
npm run simulate   # проверка баланса автоматическими игроками
```

ES-модули не работают при открытии `index.html` через `file://`, поэтому для разработки нужен `npm start`.
Готовый `dist/auction.html` самодостаточен: его можно открыть откуда угодно или выложить на любой хостинг.

## Структура

```
index.html        оболочка страницы
css/              стили по областям: tokens, base, screens, lots, auction
js/
  config.js       все числа баланса в одном месте
  data/           справочники: категории вещей, участники, реклама, штат, события
  engine/         правила игры, без DOM; состояние game передаётся первым аргументом
  ui/             интерфейс: экраны, компоненты, сцена торгов, звук, эффекты
  util/           генератор случайных чисел и форматирование
  main.js         точка входа
tools/            сборка, dev-сервер, симулятор и автоматические игроки
tests/            тесты (node --test)
docs/             подробная документация
```

## Публикация

Сборка кладёт всё в один файл, поэтому подойдёт любой статический хостинг. Для GitHub Pages: `npm run build`,
затем опубликовать `dist/auction.html` как `index.html` (или настроить Actions на сборку, см. `.github/workflows/ci.yml`).

## Разработка

- Правила и числа меняются в `js/config.js` и `js/data/`, интерфейс в `js/ui/`. Движок не знает про DOM.
- После правки баланса запустите `npm run simulate` и `npm test`. Тесты баланса падают, если игра стала слишком лёгкой или тяжёлой.
- Ограничения для сборщика (простые импорты и экспорты, уникальные имена верхнего уровня) описаны в `docs/ARCHITECTURE.md`.
